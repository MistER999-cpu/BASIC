# Paint-program video assets

Generated stills for the Windows-95 paint-program spot. Drop files straight into
the folders below, using these names — the render pipeline and the sidebar
carousel both key off them.

The application chrome, generated once.

    cursor-rest.png     pixel hand cursor, resting

## reveals/

The payoff shot for each round. Full-length, isolated on white, no shadow.

    reveal-1.png        beige tank, suede flares, cream trainers
    reveal-2.png        white tank, pinstripe palazzo, grey trainers
    reveal-3.png        black tank, pinstripe bomber, grey wide-leg, boots
    reveal-3-bare.png   as above, jacket removed - for the eraser wipe
    reveal-4.png        brown tank, suede jacket, barrel trousers, loafers
    reveal-4-bare.png   as above, jacket removed - for the eraser wipe

The `-bare` pair must register against its jacketed version: same pose, same
framing, same scale. If the body shifts between the two the wipe reads as a cut.
